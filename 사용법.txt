압축을 푼 폴더에서 최초 한 번 필요한 Python 패키지를 설치합니다.
  python3 -m pip install -r requirements.txt
가상환경을 쓰는 경우 먼저 해당 환경을 활성화하세요.

기존 양식의 연도ST_leader.xlsx와 연도ST_freshmen.xlsx를 이 폴더에 놓고 실행합니다.
  python3 main.py

행사 연도를 입력하고 화면 안내에 따르세요. 조장 명단의 조 번호는 1부터 연속으로 지정합니다.
라이브러리 설치 후 명단 처리와 결과 저장은 인터넷 없이 가능합니다.
team_result_날짜_시간.xlsx의 전체 시트에는 주민등록번호가 포함됩니다.
직접 입력으로 조장을 등록하려면 별도로 제공되는 오프라인 웹 화면을 이용하세요.
